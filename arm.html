Project Overview

项目概述

面向菌棚非结构化环境的食用菌自动化采摘难题，从机械结构、视觉识别与运动控制三个维度系统性攻关，形成完整的技术闭环。

✦技术路线

项目采取「结构设计—仿真优化—视觉识别—运动规划」四位一体的研发路径，覆盖从关键零部件到整机系统的完整设计链条。

  • 设计一代机与二代机两代整机平台，逐步提升机构冗余度与作业柔性
  • 基于 ANSYS 开展静力学、瞬态动力学、疲劳及响应面优化分析
  • 融合公开与自建数据集训练 YOLOv8 视觉识别模型
  • 针对冗余机械臂提出 MLP+PSO 融合逆运动学求解方法

⚙核心创新点

  • 三种差异化末端夹爪，适配不同规格与形态的食用菌
  • 响应面法驱动的关键部件轻量化优化设计
  • 多环境自建数据集增强模型泛化能力
  • MLP 快速解与 PSO 全局寻优相结合，解决冗余系统多解问题
Platform

整机方案：一代机与二代机

两代整机平台不断迭代，从基础采摘能力到冗余自由度柔性作业，逐步逼近真实菌棚的复杂工况。

End Effectors

三种末端夹爪设计

针对不同采摘需求，设计三种结构原理各异的末端夹爪，兼顾抓取稳定性与柔顺性，降低损伤率。

Finite Element Analysis

关键零部件有限元仿真

使用 ANSYS 对关键零部件开展静力学、瞬态动力学、疲劳分析及基于响应面的优化分析，为结构设计与轻量化提供依据。

1

静力学分析

验证夹爪、上臂与基座等关键承力零件在额定载荷下的强度与刚度，确保结构安全可靠。

2

瞬态动力学分析

对同步带传动系统进行瞬态动力学仿真，评估动态载荷下的响应特性。

3

疲劳与碰撞分析

开展肩部零件疲劳寿命分析及滑台碰撞分析，排查失效与干涉风险。

4

响应面优化分析

基于响应面法对基座、上臂零件进行结构优化，实现轻量化设计。

Computer Vision

YOLOv8 视觉识别模型

融合 Kaggle 公开数据集与自建多环境数据集训练 YOLOv8 视觉识别模型，增强模型在不同光照与背景下的泛化能力，提升采摘定位精度。

Inverse Kinematics

MLP+PSO 融合逆运动学求解

针对二代机冗余机械臂系统逆运动学的欠定多解问题，提出 MLP+PSO 融合求解方法，兼顾求解速度与全局最优性。

◈求解框架

搭建基于 Python 的逆运动学求解仿真框架，设计静态位姿求解、连续轨迹跟踪、消融实验及鲁棒性测试，系统验证方法有效性。

  • MLP 提供快速初值解，PSO 迭代收敛至全局最优
  • 静态位姿求解 + 连续轨迹跟踪双重验证
  • 消融实验与鲁棒性测试验证方法泛化能力
